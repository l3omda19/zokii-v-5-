# Zokii Studio Simple

A very simple GitHub Pages version:
- Main page: CREATE A CODE
- ADMIN page: password-protected UI
- 3-day code generation
- Codes are stored in browser localStorage

IMPORTANT:
This is a simple static/demo generator. The admin password and generated codes are client-side, so this is NOT a secure production licensing server. Do not use it as the authoritative license system for a commercial APK.
